NGS アバンダク計算ツール

NGS公開中

武器1＋防具3 × 各8スロットに付与する特殊能力を組み立てながら、重複を除いた総特殊能力数をリアルタイムで集計する計算ツール。

  • EXOP1〜3 の一括設定・解除、全複製、クリア
  • スキルリング・アミュレット (AM能力 OP枠)・数値合算にも対応
  • カスタム能力の追加・JSON バックアップ、選択状態の自動保存
  • ダーク / ライト / サイバー / ミント のテーマ切り替え
  • 単一 HTML で動作・ブラウザ完結・通信なし

NGS 情報ダッシュボード (GAS版)

NGS公開中 (v33)

公式サイトのイベントスケジュールと最新ニュースを1ページにまとめて表示する Google Apps Script 製ダッシュボード。スマホのホーム画面にも追加できます。

  • 予告緊急クエストは公式スケジュールのリンクから自動追従で取得
  • ⚡ 電撃オンライン NGS特集の最新記事3件も表示
  • 60分キャッシュ＋深夜帯は更新停止 (公式にやさしい設計)
  • セクション折りたたみ・「緊急は次の2つだけ表示」などの開閉設定を localStorage に保存
  • noindex・(C)SEGA 表記つきの非公式ファンツール
開く (公開版) GASエディタ README ソース (フォルダ)

NGS 武器どっち？

NGS公開中 (v2610b)

NGSの武器をざっくり威力比較するツール。威力＝攻撃力 × 潜在能力Lv倍率 × プリセット倍率で計算します。

  • 武器シリーズを選ぶと 強化値+100 の攻撃力と潜在能力を自動セット
  • 潜在Lv1〜6・プリセット能力（wikiの条件込み実効威力%）に対応
  • 1行目の武器を基準にした%差分を強い順にランキング表示
  • シリーズ選択で攻撃力が自動入力・行追加で比較したいだけ並べられる（データ内蔵・単一HTML）
  • 参照: NGS攻略wiki（武器・防具/シリーズ、潜在能力、プリセット能力 / 2026/10/22取得）
開く (公開版) GitHub ローカル版

pso2 暗影日程

旧PSO2公開中 (GAS)

旧PSO2の特別突破訓練＋超域クエスト（魔笛・魔城・混沌・暗影渦巻く壊れた世界 など）の日程をカード形式で表示する Google Apps Script 製ツール。

  • 本日の回しに「今日」バッジ＋枠ハイライト
  • 既定は7日分表示、「📅 30日分を表示する」ボタンで長期スケジュールに切り替え
  • クエストを色分け表示（魔笛=赤 / 魔城=黄 / 暗影=紫）
  • Wiki取得なし・日付計算のみで生成（外部通信ゼロ、値が替わるのは JST 0時だけ）
  • カードタップで PSO2 攻略 Wiki (pso2.swiki.jp) の該当クエストページを開く
  • スマホ対応のダーク UI・非公式ファンツール
開く (公開版) GASエディタ ソース (フォルダ)

PSO2 マグ育成 計算ツール

旧PSO2公開中

PSO2 (EP6時点) のマグ育成を計算するツール。「このアイテム何個で Lv200？」「何個与えるとどこまで？」がひと目でわかります。

  • 現在のマグ入力 (7ステータス＋極振りプリセット)
  • 目標までの必要個数 / 個数からの到達Lv を逆算
  • 複数アイテムを順番に与える「育成プラン」シミュレーション
  • アイテム効果の早見表、7色のテーマ
